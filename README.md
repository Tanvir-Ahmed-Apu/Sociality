A modern, full-stack social media web application built with a focus on real-time interactions, clean aesthetics, and seamless user experience.

## Features

### Currently Implemented
- **User Authentication**: Secure login and registration using JWT and Google OAuth20 integration.
- **Real-Time Communication**: Instant messaging and live notifications powered by Socket.io.
- **Media Uploads**: Seamless image uploading and management utilizing Cloudinary and Multer.
- **Modern UI/UX**: A beautiful, accessible, and interactive frontend built with React, Chakra UI, and Framer Motion.
- **State Management**: Efficient and scalable global state handling with Recoil.
- **Discord & Telegram Integration**: Bridging community interactions with Discord and Telegram bots.
